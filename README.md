# WorkLands — Visual Showcase

Galeria publica isolada de 16 mockups conceituais com quatro cenas e temas visuais alternativos. Use index.html para alternar Cena, UI e Assets.

Esta publicacao e somente uma mostra ilustrativa: nao inclui codigo ou runtime do WorkLands, nao demonstra operacao de agentes e nao modifica o escopo do MVP, atualmente Classic UI + Classic Assets com pixel art top-down 32x32.

Outras combinacoes nao ilustradas sao ajustadas para as referencias existentes. Nao ha montagem artificial de assets nem sistemas operacionais executados.
