# WorkLands — Visual Showcase

Mostra pública independente com **22 imagens conceituais**:

- **16 cenas principais:** quatro cenas para cada uma das combinações Classic/Classic, RPG/RPG, Biophilic/RPG e Industrial/RPG.
- **6 referências individuais adicionais:** Aurora/High Tech, High Tech/High Tech, RPG/High Tech, Aurora/Cyberpunk, RPG/Cyberpunk e High Tech/Cyberpunk.

Abra a [galeria interativa](https://archersland.github.io/worklands-visual-showcase/) e escolha Cena, UI ou Assets. Os botões de cenas 2 a 4 ficam indisponíveis quando a combinação selecionada possui somente uma referência individual.

**Esta galeria é apenas pesquisa visual.** Não inclui o código ou runtime privado do WorkLands, não executa agentes e não altera o recorte vigente do MVP: Classic UI + Classic Assets, mundo em pixel art top-down com tiles artísticos 32×32 e acabamento RPG clássico refinado. As imagens não representam arte final ou implementação operacional homologada.
